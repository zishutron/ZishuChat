ZishuChat website (static, no build step)

Pages
  index.html             home
  privacy.html           Privacy Policy
  terms.html             Terms of Service
  support.html           Support and contact
  about-zishutron.html   About ZishuTron
  developer.html         About the developer

Folders
  css/style.css          all styling (colors are CSS variables at the top)
  js/main.js             interactions (menu, download button, copy buttons, customizer)
  assets/img/            screenshots (webp), logo, favicon, developer photo

Download link
  Open js/main.js, find:  var DOWNLOAD_URL = "";
  Paste your link between the quotes. All "Get the app" buttons become live.

Run locally: double-click index.html.
Host: upload the whole folder to GitHub Pages, Netlify, Cloudflare Pages or any hosting.
